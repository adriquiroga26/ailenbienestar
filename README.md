# Ailen Bienestar

Landing page de Ailen Bienestar — Reiki, Access Bars y terapias holísticas en Córdoba, Argentina.

## Estructura del proyecto

```
ailen/
├── index.html
├── robots.txt
├── sitemap.xml
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── assets/
    └── img/
        └── logo-ailen.png
```

- **index.html**: única página del sitio (landing de una sola vista con navegación por anclas).
- **css/styles.css**: estilos, con variables CSS para la paleta violeta-magenta-dorado.
- **js/main.js**: lógica del menú mobile (hamburguesa accesible).
- **assets/img/**: imágenes del sitio.
- **robots.txt** / **sitemap.xml**: indexación para buscadores.

## Cómo verlo localmente

Solo hace falta abrir `index.html` en el navegador, o servirlo con una extensión tipo Live Server.
